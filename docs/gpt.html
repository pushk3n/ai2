MSICN 内部结构

IFE

6 层 3×3 卷积提取多尺度光照特征，并拼接得到 illumination features。

GIC

大感受野卷积 + 全局平均池化，输出 3 通道全局矫正系数 k。

LIC

多尺度局部矫正，输出 10 组局部系数 k_i，用于拟合复杂局部光照。

NLIS

先用 k 做全局二次曲线调整，再把 10 组 k_i 迭代堆叠到图像上。

FIE 内部结构

空间交互分支

对像素间关系建模，强调目标区域上下文，抑制背景与噪声干扰。

通道交互分支

对通道语义关系建模。(注：需通过上采样将特征图恢复至原尺寸后才能拼接)

Concat 输出

将原始特征、空间增强特征、通道增强特征拼接后送入检测头。

这张图把论文方法压缩成后续 Python 实现可直接对齐的模块粒度：训练阶段分为预训练检测器、冻结检测器训练 MSICN、再联合微调；推理阶段按 Input → MSICN → YOLOv7 Backbone/Neck → FIE → Detect/NMS 的执行顺序展开。

训练阶段

Train Pipeline / 对齐论文 3.4 节

Phase A：预训练正常照度检测器

train_detector_on_normal_light()

使用正常照度数据集训练 YOLOv7 检测器，得到具备正常光照特征提取能力的检测器参数 θ_det。

IMG_H + labels → YOLOv7 Backbone + Neck + Detect → Loss_H / θ_det

Phase B：冻结检测器，仅训练 MSICN

freeze_detector(); train_msicn_with_det_loss()

将低照度图像先送入 MSICN，再输入冻结的检测器；反向传播时仅更新 θ_msicn，使光照矫正完全朝检测精度提升方向优化。

IMG_L + labels → MSICN → Frozen Detector → Loss_C 只回传到 MSICN
  • 目标不是生成“视觉更好看”的图像，而是生成“更利于检测”的矫正结果。
  • 这里不依赖成对正常照度/低照度目标检测数据。

Phase C：解冻全模型联合微调

finetune_icfie_yolo_end_to_end()

MSICN 学到初步光照矫正关系后，解冻检测器与 FIE，进行端到端联合微调，得到最终 ICFIE-YOLO 权重。

MSICN → YOLOv7 Backbone/Neck → FIE → Detect + Loss

推理阶段

Inference Pipeline / 对齐论文 3.1 ~ 3.3 节

1. 输入低照度图像

输入张量通常为 x ∈ R[B, 3, H, W]，先归一化到 [0, 1]，后续 MSICN 与检测器均基于该范围工作。

forward(x)

2. MSICN 光照矫正

先提取光照特征，再分别估计全局与局部光照矫正参数，最后通过 NLIS 对输入图像做多次非线性光照堆叠，输出更利于检测的矫正图像。

IFE

多层 3×3 卷积提取多尺度光照特征，并拼接不同感受野特征。

IlluminationFeatureExtraction

GIC

预测全局光照系数 k，分别修正 RGB 三通道的全局亮度与色调。

GlobalIlluminationCorrection

LIC

预测 10 组局部矫正系数 K1...K10，拟合复杂局部光源与不均匀照明。

LocalIlluminationCorrection

NLIS

按论文式(1)(2)执行全局曲线矫正与 10 次局部非线性堆叠，得到 x_corr。

NonLinearIlluminationStacking
建议 Python 对齐：x_corr = self.msicn(x)，其中 msicn.forward 内部固定为 ife → (gic, lic) → nlis。

3. YOLOv7 Backbone + Neck 特征提取

将矫正后的图像送入主干与颈部网络，输出多尺度特征图 P3、P4、P5，为后续 FIE 和检测头提供基础特征。

P3

高分辨率特征，偏向小目标。

feat_small

P4

中尺度特征，兼顾局部与语义。

feat_medium

P5

高语义特征，偏向大目标。

feat_large

4. FIE 特征交互增强

对每个尺度特征分别执行空间交互增强和通道交互增强，最后与原始特征按通道拼接，抑制噪声并强化目标特征。

Spatial Branch

通过 q·cᵀ 建立像素间空间关联，突出目标区域、压制背景噪声。

spatial_interaction_branch()

Channel Branch

通过 yᵀ·p 建立通道语义关联。(注：输出前需上采样恢复原分辨率以对齐张量)

channel_interaction_branch()
建议 Python 对齐：feat_out = torch.cat([feat, f_s, f_c], dim=1)，并在 P3/P4/P5 上各放置一个 FIE 模块。

5. Detect Head + NMS 输出结果

增强后的多尺度特征进入检测头，完成分类与边框回归；推理时经 NMS 输出最终目标框、类别与置信度。

FIE(P3/P4/P5) → Detect Head → Boxes / Scores / Labels
